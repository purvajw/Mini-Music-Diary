# Mini-Music-Diary
A simple and interactive music recommender app that suggests songs based on your mood, helping users discover music that matches how they feel.

## Features

* Recommends songs based on user mood
* Simple and user-friendly interface
* Helps users discover music for different emotions

## Technologies Used

* Python
* Tkinter

## How It Works

Select your mood, and the app suggests songs that match your current emotion.

## Future Improvements

* Add more songs and moods
* Connect to music APIs
* Improve the user interface
